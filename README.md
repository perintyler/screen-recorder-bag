# Screen Recorder (Barry bag)

Record the macOS screen using FFmpeg and AVFoundation.

## Tools

- `check_screen_recording_permissions` — check if FFmpeg is installed and macOS screen recording permission is granted
- `start_screen_recording` — start screen recording on the main display
- `stop_screen_recording` — stop the current screen recording and save the file
- `screen_recording_status` — check if a screen recording is currently in progress
